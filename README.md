# Comprehensive Supply Chain Data Analysis Project

## Project Overview

This project presents an end-to-end Supply Chain Data Analysis project completed during the internship. The project covers the complete data analysis workflow, starting from problem definition and data acquisition through data cleaning, exploratory data analysis, statistical modeling, and interactive dashboard development.

The objective is to analyze supply chain data, identify meaningful patterns, evaluate important operational factors, and communicate findings through effective visualizations and an interactive dashboard.

## Project Workflow

The project was completed in the following stages:

1. Data Analysis Strategy and Planning
2. Data Acquisition and Cleaning
3. Exploratory Data Analysis and Visualization
4. Statistical Modeling
5. Interactive Dashboard Development
6. Comprehensive Project Review and Documentation

## Dataset

The project uses a Supply Chain dataset containing information related to:

* Product type
* Product SKU
* Price
* Product availability
* Number of products sold
* Revenue generated
* Stock levels
* Lead times
* Order quantities
* Shipping information
* Supplier information
* Production volumes
* Manufacturing costs
* Inspection results
* Defect rates
* Transportation modes
* Routes and costs

The dataset was cleaned and prepared before performing further analysis.

## Data Cleaning

The dataset was examined and processed for:

* Missing values
* Duplicate records
* Potential outliers
* Inconsistent categorical values
* Data type consistency
* Numerical scaling
* Categorical encoding
* Feature engineering

The IQR method was used to check for potential outliers. The analysis found no observations outside the defined IQR limits in the checked numerical variables.

## Exploratory Data Analysis

Exploratory analysis was performed to understand the distribution and relationships within the supply chain data.

The analysis included:

* Price distribution
* Revenue distribution
* Product type analysis
* Transportation mode analysis
* Inspection result analysis
* Manufacturing cost analysis
* Shipping cost analysis
* Price and revenue relationship
* Stock levels and products sold relationship
* Correlation analysis

## Statistical Modeling

A Linear Regression model was developed to study the relationship between supply chain variables and Revenue Generated.

The modeling process included:

* Feature selection
* Data preparation
* Training and testing split
* Model training
* Model testing
* Cross-validation
* Evaluation using regression metrics
* Actual versus predicted analysis
* Residual analysis
